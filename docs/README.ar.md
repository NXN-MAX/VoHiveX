# VoHiveX

[English](../README.md) | العربية | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [Français](README.fr.md) | [Русский](README.ru.md) | [Español](README.es.md) | [日本語](README.ja.md)

**المشروع الأصلي:** [VoHive](https://github.com/iniwex5/vohive) من تطوير [iniwex5](https://github.com/iniwex5)<br>
**مؤلف VoHiveX:** [NXN-MAX](https://github.com/NXN-MAX) · **الإصدار:** 2.1.4

VoHiveX منصة شخصية لإدارة وحدات الاتصال واختبارها، مشتقة من VoHive. تضيف التوافق مع وحدات DJI 4G، وجدولة الرسائل القصيرة، وإدارة اشتراكات وعُقد Mihomo، والتعرّف على رموز تفعيل eSIM، وأرشفة الرسائل، والإشعارات، وواجهة Vue متجاوبة تدعمها بوابة مكتوبة بلغة Go.

## أبرز الميزات

### التوافق مع وحدات DJI 4G

- يدعم وحدات DJI 4G من الجيل الأول التي تستخدم معرّف USB ‏`2ca3:4006`.
- يحتفظ بمعرّف USB الأصلي من DJI؛ ولا يحتاج إلى إعادة تفليش الوحدة أو تغيير المعرّف أو تعديل تعريفات المضيف بصورة دائمة.
- يطابق الجهاز وقت التشغيل مع تعريفي Linux الحاليين `option` و`qmi_wwan`، ويوفر للحاوية واجهتي AT التسلسلية وQMI.
- يمكن للجيل الثاني العمل عبر مسارات QMI أو MBIM المتوافقة التي توفرها البرامج الثابتة ونواة المضيف.

### الرسائل القصيرة المجدولة

- إرسال مرة واحدة في تاريخ ووقت محددين، أو التكرار بفواصل من الأيام والساعات والدقائق والثواني.
- إنشاء المهام وتعديلها وحذفها وبدؤها وإيقافها مؤقتًا، مع عرض موعد التنفيذ التالي وسجل التنفيذ.
- تبقى المهمة الجديدة أو المعدلة متوقفة حتى يبدأها المستخدم يدويًا. ولا تُرسل المواعيد الفائتة دفعة واحدة.
- يمكن إرسال نتائج التنفيذ والتسليم عبر قنوات Telegram وFeishu وQQ وBark والبريد الإلكتروني وPushplus وWebhook المفعّلة.

### إدارة الاشتراكات والعُقد

- يشغّل Mihomo داخل حاوية VoHiveX ويوفر نقطة SOCKS5 مدمجة وثابتة على `127.0.0.1:17890`.
- يدعم عدة اشتراكات HTTPS وملفات Clash YAML وروابط مشاركة البروكسي الشائعة.
- يوفر قوائم اشتراكات قابلة للطي، واختيار العُقد، واختبار زمن الاستجابة، وقواعد الدول لـ VoWiFi، ووكلاء خروج محليين.
- تُفك شيفرة صور QR الخاصة بالبروكسي داخل المتصفح ثم تُحذف فور انتهاء التعرّف.

### التعرّف على رموز تفعيل eSIM

- يتعرّف على صور QR، وصور الحافظة، وملفات JPG/JPEG/PNG/WebP المرفوعة، وروابط `LPA:1` المدخلة مباشرة.
- يحلل عنوان SM-DP+ وMatching ID ورمز التأكيد الاختياري ويملأ نموذج التنزيل.
- التعرّف يملأ النموذج فقط. لا تتم كتابة أي Profile حتى يراجع المستخدم القيم ويضغط **بدء التنزيل**.
- يعرض معلومات eUICC وملفات Profile المثبتة والملاحظات والتبديل والحذف عندما تدعم الوحدة والبطاقة ذلك.

### إدارة الأجهزة والرسائل

- اكتشاف الأجهزة، وحالة الشبكة اللاسلكية، وطرفيات AT وUSSD، ومعلومات SIM/eSIM، وسياسات البطاقة، وحالة VoWiFi، والسجلات المباشرة.
- مركز رسائل بثلاثة أعمدة يتضمن البحث في المحادثات، وحالة عدم القراءة، وحالة التسليم، والإجراءات المتعددة، والاستيراد والتصدير بصيغ CSV/TXT/HTML/XML.
- تتوفر Swagger UI المحلية على `/api/docs`، وفحص الصحة على `/healthz`، والمقاييس المتوافقة مع Prometheus على `/metrics`.

## البنى ومسارات المودم المدعومة

| المكوّن | الأنظمة المدعومة |
| --- | --- |
| بيئة Docker الكاملة | Linux ‏`amd64` و`arm64`/`aarch64` و`armv7` |
| بوابة Go المستقلة | Linux ‏`amd64` و`arm64`/`aarch64` و`armv7` و`386` |
| اتصال المودم | AT تسلسلي مع شبكة QMI أو MBIM متوافقة مع Qualcomm |
| واجهات نواة المضيف | `option` و`qmi_wwan` وUSB serial وجهاز تحكم QMI أو مسار MBIM متوافق |
| DJI الجيل الأول | USB ID ‏`2ca3:4006` من دون تغيير المعرّف |
| DJI الجيل الثاني | تخطيطات QMI/MBIM متوافقة؛ تعتمد الميزات على البرامج الثابتة وتركيب USB |

تُنشر الحاوية الكاملة فقط للبنى التي يتوفر لها قلب مودم مدمج ومتوافق. يحتوي تنزيل `386` على بوابة Go فقط، ويجب توصيله بقلب مودم متوافق يُوفّر بصورة منفصلة.

## التثبيت باستخدام Docker

تُنشر الصور في:

- `maxnxxn/vohivex:2.1.4`
- `ghcr.io/nxn-max/vohivex:2.1.4`

يوفر المستودعان الوسوم متعددة البنى `2.1.4` و`v2.1.4` و`latest`. يختار Docker الصورة المناسبة للمضيف تلقائيًا.

القيم الافتراضية:

- منفذ الويب: `7575`
- اسم المستخدم: `admin`
- كلمة المرور: `admin`

```sh
cp .env.example .env
docker compose pull
docker compose up -d
```

افتح `http://<عنوان-المضيف>:7575`. تبقى مجلدات `config` و`data` و`logs` و`driver-state` محفوظة أثناء التحديثات. غيّر كلمة المرور الافتراضية بعد تسجيل الدخول لأول مرة.

تكتشف الحاوية نواة المضيف العاملة وتعيد استخدام تعريفات المودم الموجودة. ولا تثبت حزم النواة أو تستبدل نواة المضيف.

## الاستخدام المسؤول والترخيص

> [!CAUTION]
> **يُحظر الاستخدام التجاري حظرًا صارمًا. VoHiveX مخصص فقط للبحث والتعلم والاختبار الشخصي على الأجهزة وأرقام الهواتف التي تتحكم بها بصورة قانونية.**

لا تستخدم VoHiveX لجمع رموز التحقق، أو تأجير الأرقام، أو إرسال رسائل غير مرغوب فيها أو جماعية، أو الاحتيال، أو تقديم خدمات بروكسي غير قانونية، أو أي نشاط يخالف القانون المحلي أو شروط شركة الاتصالات.

يحتفظ المشروع الأصلي والمكونات الخارجية بتراخيصها. تستخدم إضافات VoHiveX [رخصة الاستخدام الشخصي غير التجاري](../LICENSE)، وهي ليست رخصة مفتوحة المصدر معتمدة من OSI.
