# VoHiveX

VoHiveX — персональная платформа управления и тестирования модемов, созданная на основе VoHive. Она добавляет поддержку модулей DJI 4G, SMS по расписанию, управление подписками и узлами Mihomo, распознавание кодов активации eSIM, архив SMS, уведомления и адаптивный интерфейс Vue с шлюзом на Go.

## Основные возможности

### Поддержка модулей DJI 4G

- Поддерживает модули DJI 4G первого поколения с USB ID `2ca3:4006`.
- Сохраняет исходный USB ID DJI: перепрошивка, изменение USB ID и постоянное изменение драйверов хоста не требуются.
- Во время запуска сопоставляет устройство с существующими драйверами Linux `option` и `qmi_wwan`, предоставляя контейнеру последовательный интерфейс AT и QMI.
- Модули второго поколения могут работать через совместимые пути QMI или MBIM, предоставленные прошивкой и ядром хоста.

### SMS по расписанию

- Однократная отправка в заданные дату и время или повторение с интервалом в днях, часах, минутах и секундах.
- Создание, изменение, удаление, запуск и приостановка задач, просмотр следующего запуска и истории.
- Новые и изменённые задачи остаются приостановленными до ручного запуска. Пропущенные сообщения не отправляются одной пачкой.
- Результаты выполнения и доставки можно пересылать через включённые каналы Telegram, Feishu, QQ, Bark, Email, Pushplus и Webhook.

### Управление подписками и узлами

- Mihomo работает внутри контейнера VoHiveX и предоставляет постоянную встроенную точку SOCKS5 `127.0.0.1:17890`.
- Поддерживаются несколько HTTPS-подписок, Clash YAML и распространённые ссылки на прокси.
- Доступны сворачиваемые списки подписок, выбор узла, тест задержки, правила стран VoWiFi и локальные исходящие прокси.
- QR-изображения прокси распознаются в браузере и сразу удаляются после обработки.

### Распознавание кодов активации eSIM

- Распознаёт QR-изображения, изображения из буфера обмена, файлы JPG/JPEG/PNG/WebP и введённые вручную ссылки `LPA:1`.
- Извлекает адрес SM-DP+, Matching ID и необязательный код подтверждения в форму загрузки.
- Распознавание только заполняет форму. Profile не записывается, пока пользователь не проверит значения и не нажмёт **Начать загрузку**.
- Доступны сведения eUICC, установленные Profile, примечания, переключение и удаление, если это поддерживают модуль и карта.

### Управление устройствами и сообщениями

- Обнаружение устройств, состояние радиосети, терминалы AT и USSD, сведения SIM/eSIM, политики карты, состояние VoWiFi и журналы в реальном времени.
- Трёхколоночный центр SMS с поиском диалогов, непрочитанными сообщениями, состоянием доставки, групповыми действиями и импортом/экспортом CSV/TXT/HTML/XML.
- Локальный Swagger UI доступен по `/api/docs`, проверка состояния — по `/healthz`, метрики Prometheus — по `/metrics`.

## Поддерживаемые архитектуры и интерфейсы модема

| Компонент | Поддерживаемые цели |
| --- | --- |
| Полная среда Docker | Linux `amd64`, `arm64`/`aarch64`, `armv7` |
| Отдельный шлюз Go | Linux `amd64`, `arm64`/`aarch64`, `armv7`, `386` |
| Транспорт модема | Последовательный AT и совместимая с Qualcomm сеть QMI или MBIM |
| Интерфейсы ядра хоста | `option`, `qmi_wwan`, USB serial, устройство управления QMI или совместимый путь MBIM |
| DJI первого поколения | USB ID `2ca3:4006` без изменения USB ID |
| DJI второго поколения | Совместимые схемы QMI/MBIM; функции зависят от прошивки и USB-композиции |

Полный контейнер публикуется только для архитектур с совместимым встроенным ядром модема. Загрузка `386` содержит только шлюз Go и требует отдельно предоставленного совместимого ядра модема.

## Установка Docker

Образы публикуются в:

- `maxnxxn/vohivex:2.1.4`
- `ghcr.io/nxn-max/vohivex:2.1.4`

Оба репозитория предоставляют мультиархитектурные теги `2.1.4`, `v2.1.4` и `latest`. Docker автоматически выбирает образ для хоста.

Значения по умолчанию:

- Веб-порт: `7575`
- Имя пользователя: `admin`
- Пароль: `admin`

```sh
cp .env.example .env
docker compose pull
docker compose up -d
```

Откройте `http://<адрес-хоста>:7575`. При обновлениях существующие каталоги `config`, `data`, `logs` и `driver-state` сохраняются. После первого входа измените пароль по умолчанию.

Контейнер определяет запущенное ядро хоста и использует существующие драйверы модема. Он не устанавливает пакеты ядра и не заменяет ядро хоста.

> [!CAUTION]
> **Коммерческое использование строго запрещено. VoHiveX предназначен только для личных исследований, обучения и тестирования на устройствах и телефонных номерах, которыми вы законно управляете.**
